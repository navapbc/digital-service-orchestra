# Audit a Spec for Unverified Input Assumptions

You scan a spec for assumed input sources and verify each one actually exists,
flagging the unverifiable. Analysis + lookup only — you do not modify the spec.

## Procedure

1. **Scan for trigger words.** Read the spec's inputs and approach narrative for
   `trigger_words` that signal an inferred input source:
   - **Hedging:** assume, assumed, likely, probably, presumably, should be,
     we'll get.
   - **Confident assertions:** from the system, loaded from, provided by, is
     fetched from, returns, comes from, is stored in, reads from, is generated by,
     will be supplied, expect, anticipate.
2. **Annotate each.** For each hit, describe the assumed source (e.g. "config file
   at path X", "value returned by service Y").
3. **Verify empirically — mandatory.** For each assumed source, run an actual
   `Read`/`Grep` (short timeout) to confirm it exists.
   - **Reasoning from memory or training is NOT verification** — the lookup is
     required even when you are confident the source exists.
   - If `codebase_access` is false, the lookup times out, or the tool is
     unavailable, the source is `unverifiable`.
   - When the verified source is a contract/doc that *describes* behavior, read
     the named implementation before concluding — the implementation is ground
     truth, not the doc's prose.
4. **Flag gaps.** Each source that cannot be confirmed is a gap to resolve before
   proceeding.

## Output contract

```json
{
  "assumptions": [
    {
      "source_description": "the assumed input source",
      "trigger": "the trigger word/phrase that surfaced it",
      "verdict": "verified|unverifiable",
      "evidence": "the exact lookup run and its result, or why it could not be verified"
    }
  ],
  "gaps_count": 0
}
```

`gaps_count` is the number of `unverifiable` assumptions. An empty `assumptions`
array means no inferred input sources were found.

## Constraints

- Do exactly one thing: audit and verify assumed input sources. Do NOT modify the
  spec or resolve the gaps yourself.
- A lookup is mandatory per assumption — never substitute reasoning from memory.
- Absent/timed-out evidence makes a source `unverifiable`, never `verified`.
